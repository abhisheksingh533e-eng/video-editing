# Anime Reel
An anime-style episode with original characters drawn in code and lip-synced to your voice lines.

## Method
1. Read the script and split it into shots.
2. Draw original characters in anime style.
3. Force-align voice lines for lip-sync and add idle motion.
4. Add anime tricks like speed lines and screen shake.
5. Add captions and sound effects.

## Render Settings
- Resolution: 9:16 (reels), 16:9 (YouTube)
- Frame-by-frame rendering in headless Chrome.
- Encoded with ffmpeg.
